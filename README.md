# Мои задачи

Упрощённая персональная Kanban-доска Сергея.

- блоки оргструктуры;
- статусы задач;
- фильтры «Сегодня» и «Просрочено»;
- перетаскивание карточек;
- адаптация для телефона;
- локальное сохранение в браузере;
- выгрузка CSV для Google Таблицы.

> Текущая MVP-версия хранит задачи в `localStorage` конкретного браузера. Google Таблица создана как резервная структура; автоматическая двусторонняя синхронизация будет следующим этапом.
